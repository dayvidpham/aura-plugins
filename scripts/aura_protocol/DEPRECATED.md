# DEPRECATED — Python `aura_protocol` package

**Status:** Deprecated as of 2026-05-20.
**Successor:** The Go port at `worktree/aura-protocol/pasture/` (module `github.com/dayvidpham/pasture`).
**Tracking:** [`aura-plugins-naupi`](beads://aura-plugins-naupi)

## What this means

This package — `scripts/aura_protocol/` and its tests at `tests/test_*.py` — is
**no longer authoritative** for any runtime concern in the Aura toolkit. It is
kept in-tree for reference and historical context; do not extend it.

For all going-forward work:

- **Workflow execution** → use `pastured` (the Go Temporal worker daemon).
- **Task / audit tracking** → use the unified `protocol.TaskTracker` (Go,
  `pkg/protocol/tasktracker.go`).
- **Constraint validators (the 26 C-* checks)** → port to / use the Go side
  in `internal/temporal/` (parity audit tracked at
  [`aura-plugins-mh4ek`](beads://aura-plugins-mh4ek)).
- **Codegen (SKILL.md headers from the protocol schema)** → use the Go
  generator at `pasture/internal/codegen/skills.go` (authority audit tracked
  at [`aura-plugins-5wbhm`](beads://aura-plugins-5wbhm)).
- **Temporal search attributes** → use the Pasture-named SAs
  (`PastureEpochId` / `PasturePhase` / etc., per pasture commit
  `1b65ca3`). This Python package keeps the old `Aura*` wire names
  intentionally; the two implementations are now forked at the wire-name
  level (see [`aura-plugins-fb658`](beads://aura-plugins-fb658)).

## Why deprecated

Per the user's direction (2026-05-20):

> *"We want to leave the Python at Aura* and deprecate it, it's not used
> anywhere else or by anybody else. Go-side should have full parity."*

The Python implementation was the original prototype that established the
Aura Protocol semantics. The Go port (Pasture) has since absorbed every
substrate concern (PROPOSAL-2 epic, landed 2026-04-26) and is the only
implementation that runs in any deployment. Keeping the Python around as a
second authority creates drift risk without delivering value to anyone.

## What about the skill bodies?

The 38 `aura-plugins/skills/<role>/SKILL.md` files in the parent repo were
historically generated by `gen_skills.py` (in this package). Some were
later hand-edited; some had their generated portion regenerated by the Go
codegen (`pasture/internal/codegen/skills.go`); over time the two
generators drifted.

Reconciliation status as of 2026-05-20: 7 SKILL.md files differ between the
parent (`aura-plugins/skills/`) and Pasture (`pasture/skills/`) homes. See
[`docs/PYTHON_TO_GO_MIGRATION.md`](../../worktree/aura-protocol/docs/PYTHON_TO_GO_MIGRATION.md)
for the drift inventory and the going-forward policy.
